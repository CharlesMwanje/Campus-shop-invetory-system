ABOUT THE SYSTEM 
Campus Shop Inventory Management System is a simple  Java application designed to store, display , and update stock.
makes a validation to make sure that no negative values are input for stock quantity and unit price.



INSTRUCTIONS TO RUN THE APPLICATION 
Using Eclipse IDE
Open the java project sources files(src) and open the package labeled   package campusshopinventorymanagementsystem;
access its Main.java class file and Run it as Java Project 

expected output;
dipslay of the INITIAL PRODUCT DETAILS, UPDATED PRODUCT DETAILS, VALIDATION TEST when negative values are input
